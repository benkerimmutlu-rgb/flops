# Деплой FLOPS: вход родителя + сохранение прогресса

Стек: **Next.js + Supabase (вход по ссылке на email, облачный прогресс) + Vercel**.
Пока переменные Supabase не заданы, приложение работает локально (прогресс в
браузере, без входа). Как только добавишь ключи — включается вход и облако.

---

## 1. Supabase (вход + база)

1. Зайди на https://supabase.com → **New project** (бесплатный тариф). Запомни
   пароль БД (для входа в приложение он не нужен).
2. **SQL Editor** → вставь и выполни файл [`supabase/schema.sql`](supabase/schema.sql)
   (создаёт таблицу `profiles` и правила доступа).
3. **Authentication → Providers → Email**: включи, оставь **Email OTP / Magic Link**
   (пароль не нужен).
4. **Authentication → URL Configuration**:
   - **Site URL**: адрес прод-сайта (например `https://flops.vercel.app`).
   - **Redirect URLs**: добавь обе строки —
     `http://localhost:3000/auth/callback` и `https://ТВОЙ-домен/auth/callback`.
5. **Project Settings → API**: скопируй **Project URL** и **anon public** ключ.

> Встроенная почта Supabase годится для теста (есть лимиты). Для продакшена
> позже подключи свой SMTP в **Authentication → Emails**.

## 2. Локальная проверка

1. В папке `app` создай `.env.local` по образцу
   [`.env.local.example`](.env.local.example), вставь URL и anon-ключ.
2. `npm install` (если ещё не) → `npm run build` → `npm start`.
3. Открой http://localhost:3000 → «Войти» → введи email → перейди по ссылке из
   письма → онбординг (имя + страна) → прогресс пойдёт в облако.

## 3. Vercel (хостинг)

1. Залей репозиторий на GitHub (ветка `main`).
2. https://vercel.com → **Add New → Project** → импортируй репозиторий.
3. **Root Directory**: укажи `app` (проект лежит в подпапке).
4. **Environment Variables**: добавь `NEXT_PUBLIC_SUPABASE_URL` и
   `NEXT_PUBLIC_SUPABASE_ANON_KEY` (те же значения).
5. **Deploy**. Получишь адрес вида `https://flops-xxxx.vercel.app`.
6. Впиши этот адрес в Supabase (п.1.4: Site URL и Redirect URL `…/auth/callback`).
7. Готово — делись ссылкой.

## Как это устроено в коде

- `src/lib/supabase/*` — клиенты (браузер/сервер) + флаг `isSupabaseConfigured`.
- `src/middleware.ts` — обновляет сессию.
- `src/app/login` — вход по ссылке; `src/app/auth/callback` — приём ссылки.
- `src/app/onboarding` — имя + страна (показывает флаг).
- `src/lib/auth.tsx` — сессия и профиль ребёнка.
- `src/lib/store.tsx` — при входе грузит прогресс из облака, при изменениях
  сохраняет обратно (локальный прогресс переносится в облако при первом входе).
- `supabase/schema.sql` — таблица `profiles` (профиль + прогресс в `state`).

## Приватность (детское приложение)

- Email собираем только у **родителя**, пароля нет (вход по ссылке).
- У ребёнка — только имя и страна. Чувствительных данных не собираем.
- Для продакшена добавь страницу политики конфиденциальности и, если нужно,
  согласие родителя (COPPA/GDPR-K) — могу помочь с текстом.
