# Настенные вывески для игрового блогера

Добавлены два предмета категории «Игры», по 24 косточки:

- `fortnite_wall_sign` — «Вывеска Fortnite»: крупные белые буквы, фиолетовая основа, синяя окантовка и небольшой силуэт города.
- `toca_boca_wall_sign` — «Вывеска Toca Boca»: округлые буквы, цветная улыбка и розово-бирюзовая основа.

Обе вывески объёмные, пластилиновые, с прозрачным фоном. Ориентиры оформления: [Fortnite](https://www.fortnite.com/) и [Toca Boca](https://www.tocaboca.com/). Вывески предназначены для стены, их можно двигать, увеличивать, уменьшать, поворачивать и убирать обратно в коллекцию. В домике доступны после покупки.

Финальные картинки: `public/assets/clay/room-items/fortnite_wall_sign.webp` и `public/assets/clay/room-items/toca_boca_wall_sign.webp`. Встроенный image_gen, отдельная генерация для каждого предмета. Нормализация 512×512 сохраняет прозрачность и пропорции. Опорная точка каждого изображения рассчитана по нижней границе непрозрачной части, чтобы широкий Fortnite не смещался при размещении.

Точные промпты, исходные и итоговые пути: [манифест ассетов](2026-10-21-wall-signs-assets.json).

Новые товары идут первыми в «Новинках», предыдущие 12 сохранены. Версия объявления обновлена на `creator-signs-2026-10-21`.

Проверка: 32 теста, TypeScript, ESLint изменённых исходников, production build webpack. В изолированной мобильной сцене 375px проверены внешний вид двух вывесок, перемещение по стене и изменение размера. Тестовая коллекция не меняла покупки настоящего профиля; временная сцена удалена перед сборкой.
