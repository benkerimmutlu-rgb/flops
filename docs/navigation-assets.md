# Navigation artwork

The mobile dock uses existing FLOPS clay bitmap artwork for flags, capitals,
languages, the world and shop. The memory icon reuses the homepage's two sculpted
clay cards in CSS. No system emoji remain in the dock or shop categories.

New asset: `public/assets/navigation/clay-doghouse.webp` (240 px, transparent).
Generated with the built-in imagegen tool, then downscaled and encoded as WebP.
The generated source is preserved under Codex's generated_images directory.
